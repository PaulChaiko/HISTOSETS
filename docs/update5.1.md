# update5.1 — основа каталога, стартовый экран и просмотр

Обновление реализует основу согласованных Use Cases: выбор/создание базы, отдельный режим просмотра, полную локализацию, типовые теги и группы аналогов. Оно подготавливает модель для постоянного редактора update5.2 и сложных областей/измерений update5.3.

## Первый запуск и выбор базы

1. Распакуйте сборку **HISTOSETS-update5.1-windows-x64** целиком и запустите `HistOSets.exe`.
2. На стартовом экране проверьте логотип, название выбранной базы, число объектов и дату/время изменения. Считаются карточки объектов, а не их переводы и не все файлы изображений.
3. Чтобы выбрать базу, нажмите **«Выбрать базу данных…»** и укажите `catalog.sqlite` либо **«Выбрать папку…»** и укажите его папку.
4. Для новой базы нажмите **«Создать пустую базу данных…»**, выберите пустую папку и задайте название. Непустая неизвестная папка не используется для создания поверх существующих файлов.
5. Нажмите **«Просмотр»**. Пустая выбранная база открывается без добавления демонстрационных объектов.

Путь выбранной базы запоминается. При отсутствии настройки выбора может открыться ранее созданный каталог `%LOCALAPPDATA%/HISTOSETS/Catalog`, если в нём есть `catalog.sqlite`. Если сохранённая база исчезла, приложение сообщает об этом; новый файл на её месте не создаётся. При неудачном выборе другой базы ранее открытая остаётся выбранной.

Если своей базы нет, кнопка **«Создать учебную демонстрационную базу…»** явно импортирует комплектные `ATLAS/ATLAS.xml` и `SPECIMENS` в выбранную пустую папку. Эта кнопка доступна на стартовом экране без выбранной базы. Импорт не выполняется автоматически при запуске.

В **«Управление базой и резервные копии…»** можно переименовать базу, сохранить архив `.histosets`, восстановить архив в пустую папку, открыть другой каталог или выполнить прежние операции с XML. Название базы и название её папки независимы.

## Обновление схемы 1 до 2

1. Завершите работу с каталогом в предыдущей сборке. Один каталог нельзя одновременно открывать двумя экземплярами приложения.
2. Откройте его в update5.1. Программа проверяет прежнюю структуру и создаёт **полный архив до миграции**:

   ```text
   <каталог>/BACKUPS/before-schema2-<UTC>-<UUID>.histosets
   ```

3. После создания архива выполняется транзакционная миграция. При невозможности сохранить обязательную копию обновление не продолжается.
4. Проверьте материалы, переводы, теги и контуры. Исходные изображения и геометрия не преобразуются повторно.

Схема 2 содержит **19 таблиц**: к прежней основе добавлены группы аналогов, их переводы и калибровка. В существующие таблицы добавлены название/редакция каталога, статус объекта, основное изображение, принадлежность к аналогам и признак системного типа тега. Геометрия всё ещё хранится в `regions` и `region_points`; проект расширенной JSON-геометрии не является уже выполненной миграцией.

Исходные UUID и содержимое сохраняются. Старые пользовательские группы тегов остаются доступными и помечаются как старые. Они не объединяются с системными типами автоматически. Аналоги также не выводятся из совпадения названий.

Для возврата к update4 восстановите **архив до миграции** в другую пустую папку и откройте её предыдущей сборкой. Обновлённая схема 2 предназначена для update5.1 и последующих совместимых версий; подмена только файла базы без связанных изображений не является полным восстановлением.

## Просмотр и язык

- **РУССКИЙ | ENGLISH** на стартовом экране либо выбор языка в просмотре переключает интерфейс и содержимое. Язык сохраняется между окнами и запусками.
- Щелчок по объекту показывает его изображение и краткое описание; щелчок по элементу — описание элемента и принадлежащие ему области.
- Колесо мыши и **`+` / `−`** меняют масштаб. Удерживание левой кнопки перемещает изображение. При выходе за границы окна видна обзорная миниатюра; щелчок по ней переносит видимую часть.
- **`100 %`** показывает исходный масштаб: один пиксель изображения на одну логическую единицу WPF. При системном масштабировании Windows это не обязательно один физический пиксель экрана.
- **«Вписать»** целиком размещает изображение в доступной области. Эта команда отличается от `100 %`.
- **«Области»**, **«Видимость»**, **«Оттенок»** управляют показом выбранных областей. Эти действия не меняют координаты в базе.
- **«Об объекте»** и **«Об элементе»** открывают полные описания. **A− / A+** меняют размер текста.
- **«Метаданные»** показывает назначенные теги и группу аналогов. Это окно предназначено для чтения.
- **«На главную»** возвращает на стартовый экран; выбранная база остаётся открытой.

При отсутствии нужного перевода старые данные показываются на доступном языке с пояснением. Пустые научные описания не дописываются автоматически.

Поиск проверяет названия объектов и групп аналогов **на обоих языках**. Он не различает регистр и е/ё; несколько слов должны присутствовать в поисковых данных. Поиск по полным описаниям и морфологический поиск не реализованы. Можно выбрать исходный порядок или сортировку по названию.

## Типовые теги

Системой предусмотрены **Автор, Организация, Предметная область, Тема, Назначение, Прочее**. Системные типы нельзя переименовать или удалить. Пользователь создаёт и переиспользует значения внутри типов; значения не заполняются из научных текстов автоматически.

1. Выберите объект и нажмите **«Теги…»** на верхней панели. Без выбранного объекта эта кнопка открывает общий справочник.
2. Выберите тип. Найдите существующее значение по RU/EN либо создайте новое. Новый тег должен иметь тип; для незавершённого значения допускается пока один перевод.
3. Отметьте нужные значения и нажмите **«Сохранить теги объекта»**. Назначения относятся ко всему объекту.
4. При выходе с изменёнными отметками выберите сохранение, отказ от изменений или продолжение работы.

Создание, переименование, перенос и удаление значений справочника сохраняются сразу. Отказ от несохранённых отметок объекта не отменяет уже сохранённую правку общего словаря. Удаление тега снимает его с использующих объектов после подтверждения.

Старые пользовательские группы сохраняются. Через редактирование тега его можно перенести в нужный системный тип. Старую группу с активными тегами удалить нельзя; сначала перенесите или удалите значения.

Для фильтрации раскройте **«Фильтры по тегам»**, найдите тип и выберите значения. Выбранные значения отображаются отдельно и удаляются из фильтра по **×**. Внутри одного типа действует **ИЛИ**, между типами — **И**: например, (автор A ИЛИ автор B) И тема C. Поиск по названию продолжает действовать вместе с тегами. **«Сбросить фильтры»** очищает запрос и выбранные теги.

## Группы аналогов

Аналоги — учебная группа объектов с общим допустимым названием. Это самостоятельный справочник, а не тип тега и не учёт физического препарата.

1. Выберите объект и нажмите **«Аналоги…»**. Без выбранного объекта открывается общий справочник.
2. Создайте группу с названиями **RU и EN** либо выберите существующую.
3. Нажмите **«Сохранить назначение»**. В списке появится название **«Группа — объект»**.
4. Для снятия связи выберите **«Без группы аналогов»** и сохраните назначение.

У объекта может быть максимум одна группа. Изменения общего справочника сохраняются сразу, назначение объекту — отдельной командой. Группу с назначенными объектами удалить нельзя. Группы уже учитываются в поиске; их использование как допустимых ответов относится к будущей самопроверке.

## Готовность и границы этапа

В хранилище реализованы статусы `draft` и `ready` и явная операция проверки готовности. Проверка учитывает основное изображение, обязательные названия/описания RU/EN, тексты элементов, назначенные теги и группу аналогов, а также доступность файлов. Наличие двух языков интерфейса само по себе не подтверждает полноту переводов содержимого.

**В update5.1 отдельной пользовательской кнопки проверки готовности и редактора этих полей ещё нет.** Эти операции подготовлены для следующего редактора и проверяются на уровне хранения. Неполные старые данные сохраняются; автоматического заполнения нет. Изменение связанных метаданных, из-за которого данные становятся неполными, снимает готовность. Черновик не скрывается из обычного просмотра только из-за своего статуса.

Подготовлено хранение независимого физического масштаба по X/Y на связи объекта с изображением. Внутренние величины схемы 2 заданы в метрах на пиксель. **Интерфейс ввода калибровки и вывод измерений в эту версию не входят.** DPI изображения не считается физической калибровкой.

Следующие этапы добавят:

- update5.2 — редактирование карточек и элементов, сохранение векторных областей, отмену и защиту несохранённых правок;
- update5.3 — кисть/ластик, сложные области, интерфейс калибровки и расчёт площади/периметра;
- update6 — обмен и объединение каталогов;
- update7 — шесть методов самопроверки.

Пробный браузерный редактор остаётся техническим прототипом. Его рисование не сохраняется в каталог. Основной просмотр update5.1 выполняется в WPF и не требует WebView2.

## Приёмка

| Проверка | Ожидаемый результат |
|---|---|
| Первый запуск без настроек и старого каталога | Стартовый экран без выбранной базы; просмотр отключён; демонстрационный импорт выполняется только явной командой |
| Создание пустой именованной базы | На стартовом экране указанное название и 0 объектов; просмотр сообщает о пустом каталоге |
| Открытие старой схемы 1 | Создан полный архив `before-schema2-…histosets`; база открывается в схеме 2 |
| Демонстрационный набор | 5 объектов, 5 изображений, 10 переводов карточек, 27 элементов, 33 общие области; исходные описания и контуры сохранены |
| RU/EN и повторный запуск | Меняются интерфейс и тексты; выбранные язык и путь сохраняются |
| Масштаб и перемещение | Работают колесо, `+`/`−`, `100 %`, «Вписать», перетаскивание и миниатюра; границы областей остаются привязаны к изображению |
| Настройки показа | Видимость, непрозрачность и оттенок меняют отображение; переключение элемента не оставляет чужие области |
| Поиск `CORNEA` при RU | Остаются два объекта роговицы; отсутствующий запрос даёт пустой результат; сброс возвращает объекты |
| Теги | Созданное значение переиспользуется; назначения сохраняются; фильтры дают ИЛИ внутри типа и И между типами |
| Аналоги | Назначение сохраняется после перезапуска; отображается двойное название; поиск находит по названию группы; занятую группу удалить нельзя |
| Резервная копия | Восстановление в отдельную пустую папку сохраняет название, объекты, теги, аналоги и контуры |
| Пропавший путь или ошибочная новая база | Понятная ошибка; отсутствующая база не создаётся; при неудачной смене прежняя выбранная база доступна |
| Возврат из просмотра | Стартовый экран снова доступен; база не теряет блокировку и не открывается второй раз независимо |

Набор автоматизации включает проверки ядра, хранения, браузерного прототипа и окон Windows. Успешность конкретного коммита проверяется по GitHub Actions; до завершения Windows-задачи эта инструкция не подтверждает готовность Windows-сборки. Скриншоты smoke-проверок сохраняются в артефакте `windows-smoke-results`.
