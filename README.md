# HISTOSETS

Настольный атлас изображений с описаниями и разметкой анатомических и гистологических элементов. Исходная версия зафиксирована коммитом [`3722be1`](https://github.com/PaulChaiko/HISTOSETS/commit/3722be1b2a62c445070271d68d45e33be64950f3). Ветка `update1` восстанавливает надёжный запуск и позволяет проверить новый способ просмотра.

## Запуск готовой сборки

1. Откройте [GitHub Actions](https://github.com/PaulChaiko/HISTOSETS/actions/workflows/windows.yml) и последнюю успешную проверку ветки `update1`.
2. Скачайте артефакт **HISTOSETS-update1-windows-x64**. Для скачивания артефактов GitHub требуется вход в аккаунт.
3. Распакуйте весь архив в доступную для чтения папку и запустите `HistOSets.exe`.

Сборка предназначена для Windows x64 с поддержкой .NET 10. Среда .NET включена в архив. Папки `ATLAS`, `SPECIMENS` и `Viewer` должны оставаться рядом с программой. Запуск через ярлык из другой рабочей папки поддерживается.

Для отдельного окна **«Новый просмотрщик»** нужен установленный [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section). После установки просмотр работает с локальными файлами без доступа к интернету. Основное окно атласа работает и без WebView2.

## Что входит в update1

- Исправленный запуск WPF, единое пространство имён `HistOSets`, переход на .NET 10 LTS.
- Сохранено фирменное оформление: фон `LOGO/GBL.png`, центральный логотип `LOGO/LOGO2.png` до выбора препарата, сиреневый список препаратов и розовый список элементов. Новый просмотрщик использует эти же изображения и палитру.
- Каталог загружается один раз; выбор препарата и элемента выполняется одним щелчком.
- Понятные сообщения при ошибках XML, отсутствии изображения или незаполненном описании. После исправления XML каталог можно перечитать кнопкой **«Обновить каталог»**.
- Контуры старого XML переводятся из единиц WPF в пиксели с учётом DPI исходного изображения. XML и исходные изображения сохранены без изменений.
- Новый просмотрщик: приближение, перемещение, обзорная миниатюра, подсветка элементов, настройка заливки и показ/скрытие контуров.
- Пробное рисование прямоугольников и полигонов. **Изменения в этом окне не сохраняются**; это проверка технологии для будущего редактора.
- Открытие готовых локальных пирамид DZI. Рядом с `name.dzi` должна находиться папка `name_files`. Создание пирамид и импорт больших изображений появятся позднее.
- Автоматические проверки каталога, браузерного просмотрщика, запуска WPF и переносимой Windows-сборки.

Текущий набор: 10 записей на русском и английском языках, 5 используемых изображений, 54 элемента, 66 полигонов. Пустые описания и отсутствующие контуры не дополняются автоматически.

## Сборка из исходников

Нужны Windows, .NET SDK 10 и Node.js 24 LTS. Версии JS-зависимостей зафиксированы в `Viewer/package-lock.json`; скачивание зависимостей нужно только для сборки.

```powershell
npm ci --prefix Viewer
npm run build --prefix Viewer
dotnet build HistOSets.sln -c Release --warnaserror
dotnet run --project HistOSets.csproj -c Release
```

Получение переносимой сборки:

```powershell
dotnet publish HistOSets.csproj -c Release -r win-x64 --self-contained true -o artifacts/HISTOSETS-update1-windows-x64
```

## Проверки

Проверки данных запускаются на Windows и Linux:

```powershell
dotnet run --project tests/HistOSets.Core.Tests -c Release -- .
```

Проверки просмотрщика требуют Python 3.12 и Chromium для Playwright:

```powershell
python -m pip install Pillow==12.1.1
python Viewer/tests/make-fixtures.py
npm exec --prefix Viewer -- playwright install chromium
npm test --prefix Viewer
```

На Windows дополнительно проверяются настоящее окно WPF, все препараты и контуры, отсутствие блокировки файла изображения и связка WPF → WebView2 → локальные изображения:

```powershell
dotnet run --project tests/HistOSets.Windows.Smoke -c Release -- artifacts
```

Синтетическая пирамида 16 384 × 12 288 проверяет загрузку тайлов. Она не заменяет испытания на настоящих сканах препаратов сверхвысокого разрешения. Обычный JPEG в новом просмотрщике декодируется целиком; для больших изображений используйте подготовленные DZI.

## Дальнейшая работа

[План обновлений](docs/ROADMAP.md) и [технические решения update1](docs/update1.md).

Журналы ошибок: `%LOCALAPPDATA%/HISTOSETS/Logs`. Данные браузерного компонента: `%LOCALAPPDATA%/HISTOSETS/WebView2`. Исходный каталог не записывается при просмотре.

Уведомления о лицензиях библиотек просмотрщика включаются в `Viewer/THIRD-PARTY-NOTICES.txt` готовой сборки. Условия Microsoft WebView2 поставляются с соответствующим компонентом; [документация по распространению](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution).
